HOW TO TEST
1. Open index.html.
2. Enter a name and complete all 8 scenarios.
3. Choose both correct and wrong answers during testing.
4. Verify:
   - correct answer highlights green
   - selected wrong answer highlights red
   - score updates correctly
   - Book 3 / Book 4 feedback displays
   - "Why it matters at work" displays
   - final category scores appear
   - missed scenarios are listed
   - Print / Save Certificate opens browser print dialog
   - Restart returns to start screen
5. Test on both a phone and laptop.
